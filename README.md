# Smart Hospital Management System

Smart Hospital is a college project developed to make some of the basic hospital activities easier. It provides separate sections for patients, doctors, and administrators.

The main idea behind this project is to manage appointments, patient details, and queues through a single web application.

## Features

**Patient**
- Register and log in.
- Book appointments with doctors.
- View appointment details.

**Doctor**
- Log in to the doctor dashboard.
- View appointments.
- Manage the patient queue.
- Call the next patient.

**Admin**
- View the list of patients and doctors.
- Search for patients and doctors.
- Check basic dashboard details.
- Add new doctor accounts.

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MySQL

## How to Run the Project

1. Clone this repository.
2. Open the project folder in VS Code.
3. Run `npm install` in the terminal.
4. Set up the MySQL database using `database.sql`.
5. Create a `.env` file and add your database details.
6. Start the server using:

```bash
node server.js
```

7. Open `http://localhost:3000` in your browser.
